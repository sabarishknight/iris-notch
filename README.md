


# Iris-Notch 👁️✨

A macOS menu-bar utility that gently reminds you to:
- 👁️ Blink regularly
- 🪟 Look away and rest your eyes

Designed to live around the MacBook notch with
Apple-like glow animations.

## Features
- Blink reminders
- Look-away reminders
- Pause / Resume
- Launch at Login
- Smart fullscreen detection
- Notch-aware overlay UI

## Tech
- Swift
- SwiftUI
- AppKit (NSPanel overlays)
- macOS
